## 本阶段边界

本目录只承载 M1 的评测契约、运行记录与结果。产品门槛以 `PROJECT_PROPOSAL.md` 为准，历史事实与冻结输入仍以 `evals/m0/` 为准。

当前首先锁定：

- `DiagnosisState` 的事实修订、引用、工具运行、对客答复、内部备注和升级字段；
- 知识条目的负责人、状态、可见性、有效期和复审字段；
- 7 类只读模拟工具的输入、结果和失败记录；
- 单案例运行记录中的模型、Prompt/规则版本、原始输入、工具调用、输出、引用、升级和人工七项评分。

M1 暂不接真实 CRM、写操作或公开前端。模型供应商、数据部署地区、知识负责人和复审规则确认前，不执行正式知识增强评分。
